
Execute Playwright all Test case
    npx playwright test

Execute Playwright tets cases in headed mode
    npx playwright test --headed

Execute Playwright tets cases in headed mode
    npx playwright test --project=firefox --headed

Execute particular SPEC file
    npx playwright test .FolderName/fileName.Spec.ts
    or npx playwright test fileName.Spec.ts

Execute particular test file using partial or Exact description
    npx playwright test -g "Test description Partial or Exact"


Execute playwright test in test runner
    npx playwright test --ui

Execute playwright test in Trace
    npx playwright test --trace on

Debug playwright test with playwright inspector
    npx playwright test --grep "Test Description" --debug

Record and Play playwright test with playwright inspector
    npx playwright codegen
